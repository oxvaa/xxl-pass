# XXL PASS 1.0

Festival companion prototype for XXL CZECHIA · Arena Takedown · September 2027.

## Included
- Home + LIVE mode preview
- XXL digital pass + local entry-code prototype
- Lineup and artist detail
- Personal schedule, favourites and reminders
- Venue map concept
- Merch reservation flow
- XXL Rewards / XP
- My Crew zone sharing prototype
- Notifications
- Post-event Memories preview
- Local persistence via AsyncStorage

## Expo Snack workflow
The repository includes `snack-payload-1.0.0.json` and `index.html`.
Publish GitHub Pages from `main` / `root`, open the Pages URL and tap **Create new Snack**.

The pass QR, crew locations, ticketing, Apple Wallet and payments are prototype-only until connected to production services.
